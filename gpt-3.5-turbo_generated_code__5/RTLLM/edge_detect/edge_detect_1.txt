```verilog
module edge_detect (
  input wire clk,
  input wire rst_n,
  input wire a,
  output reg rise,
  output reg down
  );

  reg a_prev;

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      rise <= 0;
      down <= 0;
      a_prev <= 0;
    end
    else begin
      a_prev <= a;
      if (a_prev == 0 && a == 1)
        rise <= 1;
      else if (a_prev == 1 && a == 0)
        down <= 1;
      else begin
        rise <= 0;
        down <= 0;
      end
    end
  end
endmodule
```
In the above code, a_prev is a register that stores the previous value of input signal "a". On each positive edge of the clock, the module checks for rising and falling edges by comparing the current and previous values of "a". If a rising edge is detected (i.e., a_prev=0 and a=1), the rise output signal is set to 1. If a falling edge is detected (i.e., a_prev=1 and a=0), the down output signal is set to 1. If neither a rising nor falling edge is detected, both output signals remain 0. The output signals are synchronized with the clock and remain set to 1 until the next corresponding edge appears. The module also includes a reset functionality, which resets the output signals and a_prev register to 0 when the reset signal (rst_n) is low.
