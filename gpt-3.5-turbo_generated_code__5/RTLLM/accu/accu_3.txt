Here's the complete Verilog code for the accu module:

```verilog
module accu (
    input clk,
    input rst_n,
    input [7:0] data_in,
    input valid_in,
    output reg valid_out,
    output reg [9:0] data_out
);

reg [7:0] accum[3:0]; // Array to store 4 input data values
reg [3:0] count; // Counter to keep track of valid input data

always @(posedge clk or negedge rst_n) begin
    if (~rst_n) begin
        valid_out <= 0;
        data_out <= 0;
        count <= 0;
        for (int i=0; i<4; i=i+1) begin
            accum[i] <= 8'b0;
        end
    end
    else begin
        if (valid_in) begin
            accum[count] <= data_in;
            count <= count + 1;
            if (count == 3) begin
                data_out <= {1'b0, accum[3]} + accum[2] + accum[1] + accum[0]; // Accumulate 4 input values
                valid_out <= 1; // Set valid_out to 1
                count <= 0; // Reset the count for next accumulation
            end
            else begin
                valid_out <= 0;
            end
        end
    end
end

endmodule
```

This module takes 8-bit input data and accumulates 4 input data values before outputting the accumulated sum and setting the valid_out signal to 1. It also includes a reset signal for initialization and a clock signal for synchronization.
