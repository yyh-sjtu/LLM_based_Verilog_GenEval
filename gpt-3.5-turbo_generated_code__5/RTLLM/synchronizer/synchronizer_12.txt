Here is the complete code for the multi-bit MUX-based synchronizer in Verilog:

```verilog
module synchronizer (
  input wire clk_a,
  input wire clk_b,
  input wire arstn,
  input wire brstn,
  input wire [3:0] data_in,
  input wire data_en,
  output reg [3:0] dataout
);

  reg [3:0] data_reg;
  reg en_data_reg;
  reg en_clap_one;
  reg en_clap_two;
  
  always @(posedge clk_a or negedge arstn) begin
    if (!arstn) begin
      data_reg <= 4'b0;
      en_data_reg <= 1'b0;
    end else begin
      data_reg <= data_in;
      en_data_reg <= data_en;
    end
  end
  
  always @(posedge clk_b or negedge brstn) begin
    if (!brstn) begin
      en_clap_one <= 1'b0;
      en_clap_two <= 1'b0;
    end else begin
      en_clap_one <= en_data_reg;
      en_clap_two <= en_clap_one;
    end
  end
  
  always @(posedge clk_b or negedge brstn) begin
    if (!brstn) begin
      dataout <= 4'b0;
    end else begin
      if (en_clap_two) begin
        dataout <= data_reg;
      end
    end
  end

endmodule
```

This code implements the multi-bit MUX-based synchronizer with the desired functionality. It includes separate registers for storing the input data, input enable, and enable control signals. On the appropriate clock edges, these registers are updated and the output data value is assigned accordingly. The reset signals are used to initialize the registers to their default values when in a reset state.
