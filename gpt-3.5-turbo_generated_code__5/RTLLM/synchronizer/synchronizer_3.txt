Here is the complete code for the implementation of the multi-bit MUX-based synchronizer:

```verilog
module synchronizer(
  input wire clk_a,
  input wire clk_b,
  input wire arstn,
  input wire brstn,
  input wire [3:0] data_in,
  input wire data_en,
  output reg [3:0] dataout
);

  reg [3:0] data_reg;
  reg en_data_reg;
  reg en_clap_one;
  reg en_clap_two;

  always @(posedge clk_a or negedge arstn) begin
    if (~arstn) begin // Reset condition
      data_reg <= 4'b0;
      en_data_reg <= 0;
    end else begin
      data_reg <= data_in;
      en_data_reg <= data_en;
    end
  end

  always @(posedge clk_b or negedge brstn) begin
    if (~brstn) begin // Reset condition
      en_clap_one <= 0;
      en_clap_two <= 0;
      dataout <= 4'b0;
    end else begin
      en_clap_one <= en_data_reg;
      en_clap_two <= en_clap_one;
      if (en_clap_two)
        dataout <= data_reg;
    end
  end

endmodule
```

In this code, the input signals `clk_a`, `clk_b`, `arstn`, `brstn`, `data_in`, and `data_en` are defined as `input` wires. The output signal `dataout` is defined as an `output reg` bus.

The module includes two registers `data_reg` and `en_data_reg` to store the input data and input enable signals, respectively. On the positive edge of `clk_a` or the falling edge of `arstn`, these registers are updated. If `arstn` is low, indicating a reset condition, the registers are set to 0. If `arstn` is high, the registers are updated with the input signals.

Two additional registers `en_clap_one` and `en_clap_two` are included to control the selection of the input data. On the positive edge of `clk_b` or the falling edge of `brstn`, these registers are updated. If `brstn` is low, indicating a reset condition, both registers are set to 0. If `brstn` is high, the registers are updated based on the value of `en_data_reg`. `en_clap_one` is assigned the value of `en_data_reg`, and `en_clap_two` is assigned the previous value of `en_clap_one`.

Finally, on the positive edge of `clk_b` or the falling edge of `brstn`, the module assigns the output data value. If `brstn` is low, indicating a reset condition, the output data `dataout` is set to 0. If `brstn` is high and `en_clap_two` is active, the output data is assigned the value of `data_reg`. If `en_clap_two` is inactive, the output data retains its previous value.
