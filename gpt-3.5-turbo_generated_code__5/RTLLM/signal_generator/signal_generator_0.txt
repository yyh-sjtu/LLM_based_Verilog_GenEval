```verilog
module signal_generator(
  input clk,
  input rst_n,
  output reg [4:0] wave
);

  reg [1:0] state;

  always @(posedge clk or negedge rst_n) begin
    if (~rst_n) begin
      state <= 0;
      wave <= 0;
    end
    else begin
      case(state)
        2'b00:
          begin
            if (wave == 5'b11111) // Reached maximum value
              state <= 2'b01;
            else
              wave <= wave + 1;
          end
        2'b01:
          begin
            if (wave == 5'b00000) // Reached minimum value
              state <= 2'b00;
            else
              wave <= wave - 1;
          end
        default: state <= 2'b00; // Reset state
      endcase
    end
  end

endmodule
```

This module uses a 2-bit state register to control the waveform generation. The waveform itself is represented by a 5-bit register called "wave". The state and waveform registers are updated on the positive edge of the clock signal or the negative edge of the reset signal.

The waveform generation is controlled using a case statement inside the always block. If the state is "00", the waveform is incremented by 1 until it reaches the maximum value of 31. At that point, the state transitions to "01" and the waveform is decremented by 1 until it reaches the minimum value of 0. Then, the state transitions back to "00" and the waveform starts incrementing again.

Please note that this code assumes a 50% duty cycle for the clock signal and uses a synchronous reset. The waveform output "wave" should be connected to the desired target in your design.
