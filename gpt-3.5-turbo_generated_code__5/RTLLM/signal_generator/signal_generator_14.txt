```verilog
module signal_generator (
    input wire clk,
    input wire rst_n,
    output reg [4:0] wave
);

    reg [1:0] state;

    always @(posedge clk or negedge rst_n) begin
        if (~rst_n) begin
            state <= 2'b00;
            wave <= 5'b00000;
        end else begin
            case (state)
                2'b00: begin
                    wave <= wave + 1;
                    if (wave == 5'b11111)
                        state <= 2'b01;
                end
                2'b01: begin
                    wave <= wave - 1;
                    if (wave == 5'b00000)
                        state <= 2'b00;
                end
            endcase
        end
    end
endmodule
```

In this code, the `signal_generator` module takes in a clock signal (`clk`), an active-low reset signal (`rst_n`), and outputs a 5-bit waveform signal (`wave`).

The module includes a 2-bit register (`state`) to control the state of the waveform generation. It also includes a 5-bit register (`wave`) to hold the generated waveform.

The always block triggers on the positive edge of the clock signal (`posedge clk`) or the negative edge of the reset signal (`negedge rst_n`). When reset is active, indicated by `~rst_n`, the state register is cleared to `2'b00` and the wave register is cleared to `5'b00000`.

Inside the always block, a case statement is used to determine the action based on the current state. If the state is `2'b00`, the waveform (`wave`) is incremented by 1. If the waveform reaches its maximum value (31 or `5'b11111`), the state is transitioned to `2'b01`.

If the state is `2'b01`, the waveform is decremented by 1. If the waveform reaches its minimum value (0 or `5'b00000`), the state is transitioned back to `2'b00`.

This design creates a continuous cycle between 0 and 31 for the waveform based on the state transitions.
