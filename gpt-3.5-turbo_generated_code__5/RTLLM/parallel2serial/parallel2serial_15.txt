Here is the complete code for the parallel-to-serial conversion module in Verilog:

```verilog
module parallel2serial (
  input wire clk,
  input wire rst_n,
  input wire [3:0] d,
  output wire valid_out,
  output wire dout
);

  reg [2:0] cnt;
  reg [3:0] data;
  reg valid;
  
  always @ (posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      cnt <= 0;
      data <= 0;
      valid <= 0;
    end
    else begin
      if (cnt == 3) begin
        data <= d;
        cnt <= 0;
        valid <= 1;
      end
      else begin
        cnt <= cnt + 1;
        valid <= 0;
        data <= {data[2:0], data[3]};
      end
    end
  end

  assign valid_out = valid;
  assign dout = data[3];

endmodule
```

In this design, we have a 3-bit counter `cnt` to keep track of the position within the 4-bit parallel input `d`. The 4-bit `data` register is used to shift the bits and hold the converted data. The `valid` signal is set to 1 when valid output is available.

On each positive edge of the `clk` signal, or when `rst_n` is low indicating a reset, the `always` block is triggered. If `rst_n` is low, the counter, data, and valid signals are reset. Otherwise, if `cnt` is 3 (indicating the last bit of parallel input), the `data` register is updated with the new input `d`, the counter `cnt` is reset to 0, and the `valid` signal is set to 1. Otherwise, the counter is incremented, the `valid` signal is set to 0, and the `data` register is shifted to the left, with the most significant bit shifted to the least significant bit.

The `valid_out` output is assigned with the value of `valid`, and the `dout` output is assigned with the most significant bit of the `data` register.
