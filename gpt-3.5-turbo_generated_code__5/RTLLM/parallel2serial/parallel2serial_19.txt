Here is the complete code for the parallel-to-serial conversion module in Verilog:

```verilog
module parallel2serial(
  input wire clk,      // Clock signal
  input wire rst_n,    // Reset signal
  input wire [3:0] d,  // 4-bit parallel data input
  
  output wire valid_out,  // Valid signal
  output wire dout        // Serial output
);

  reg [3:0] data;    // Data register
  reg [1:0] cnt;     // Counter register
  
  always @(posedge clk or negedge rst_n) begin
    if (~rst_n) begin
      // Reset state
      cnt <= 2'b00;
      data <= 4'b0000;
      valid_out <= 0;
      dout <= 1'b0;
    end
    else begin
      // Counter increment
      if (cnt == 2'b11)
        cnt <= 2'b00;
      else
        cnt <= cnt + 1;
      
      // Data shifting
      data <= {data[2:0], d[3]};
      
      // Valid signal
      if (cnt == 2'b11)
        valid_out <= 1;
      else
        valid_out <= 0;
      
      // Serial output
      dout <= data[3];
    end
  end
  
endmodule
```

This code defines a module named "parallel2serial" that takes in the clock signal, reset signal, and the 4-bit parallel input (d). It also provides the valid signal (valid_out) and the serial output (dout).

Inside the always block, the behavior of the module is defined. The counter (cnt) keeps track of the current bit being processed. During reset, the counter is initialized to 0 and the data register (data) is cleared. Additionally, the valid signal (valid_out) and serial output (dout) are set to 0.

On each clock edge, unless the reset signal is active, the counter is incremented by 1. If the counter reaches 3 (indicating the last bit of the parallel input), it is reset to 0. The data register is shifted left by 1 bit, with the most significant bit of the parallel input assigned to the least significant bit of the data register.

The valid signal is set to 1 when the counter reaches 3, indicating that the serial output is valid. Otherwise, it is set to 0. The serial output is assigned to the most significant bit of the data register.

Please note that this code assumes a positive edge-triggered clock signal and active-low reset signal (rst_n). Feel free to modify the code as per your specific requirements.
