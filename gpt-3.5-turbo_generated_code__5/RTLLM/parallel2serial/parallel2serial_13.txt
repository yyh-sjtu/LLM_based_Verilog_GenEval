Here is the complete code for the parallel-to-serial conversion module in Verilog:

```verilog
module parallel2serial(
    input wire clk,
    input wire rst_n,
    input wire [3:0] d,
    output wire valid_out,
    output wire dout
);

    reg [2:0] cnt;      // Counter register
    reg [3:0] data;     // Data register

    always @(posedge clk or negedge rst_n) begin
        if(!rst_n) begin
            cnt <= 0;   // Reset counter
            data <= 0;  // Reset data register
            valid_out <= 0;
            dout <= 0;
        end
        else begin
            if(cnt == 3) begin
                data <= d;      // Update data register with parallel input
                cnt <= 0;       // Reset counter
                valid_out <= 1; // Set valid signal to indicate availability of serial output
                dout <= data[3]; // Serial output is the most significant bit of data
            end
            else begin
                cnt <= cnt + 1; // Increment counter
                valid_out <= 0; // Reset valid signal
                data <= {data[2:0], 1'b0}; // Shift data register one bit to the left
                dout <= data[3]; // Serial output is the most significant bit of data
            end
        end
    end

endmodule
```

This module, `parallel2serial`, takes in a 4-bit parallel input `d` and converts it to a serial output `dout`. The output signal `valid_out` is set to 1 to indicate the availability of valid serial output.

On each clock cycle, the module checks the value of the counter `cnt`. If `cnt` is equal to 3, indicating the last bit of the parallel input, the module updates the data register `data` with the parallel input `d`, resets the counter `cnt` to 0, and sets the valid signal `valid_out` to 1. The serial output `dout` is then assigned the most significant bit of the `data` register.

If `cnt` is not equal to 3, the module increments the counter `cnt` by 1, sets the valid signal `valid_out` to 0, and shifts the data register `data` one bit to the left, with the most significant bit shifted to the least significant bit. The serial output `dout` is again assigned the most significant bit of the `data` register.

The module also includes a synchronous reset functionality, where if the reset signal `rst_n` is high, the counter register `cnt` is incremented by 1, and the data register `data` is reset to 0. The valid signal `valid_out` and serial output `dout` are also set to 0.
