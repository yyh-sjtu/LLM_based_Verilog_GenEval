```verilog
module serial2parallel (
  input wire clk,
  input wire rst_n,
  input wire din_serial,
  input wire din_valid,
  output reg [7:0] dout_parallel,
  output reg dout_valid
);

  reg [3:0] cnt;

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      cnt <= 0;
      dout_parallel <= 0;
      dout_valid <= 0;
    end
    else begin
      if (din_valid) begin
        if (cnt < 7) begin
          dout_parallel <= {din_serial, dout_parallel[7:1]};
          cnt <= cnt + 1;
        end
        else begin
          dout_parallel <= {din_serial, dout_parallel[7:1]};
          dout_valid <= 1;
          cnt <= 0;
        end
      end
    end
  end

endmodule
```

In this implementation, we have a synchronous design where the module operates on the rising edge of the `clk` signal. The `rst_n` signal is the active-low reset signal, which resets the `cnt` counter and `dout_parallel` and `dout_valid` output signals to their initial values when asserted.

The `cnt` counter keeps track of the number of serial input data bits received. Whenever `din_valid` signal is high, the module checks if the `cnt` is less than 7 (indicating that not all 8 bits have been received yet). If so, it shifts the current `din_serial` input value into the `dout_parallel` register, shifting the existing data to the right, and increments the `cnt` counter. If the `cnt` reaches 7, it performs the same shifting operation but also sets `dout_valid` signal to 1.
