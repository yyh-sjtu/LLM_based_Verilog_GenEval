```verilog
module serial2parallel(
  input clk,        // Clock signal
  input rst_n,      // Reset signal (active low)
  input din_serial, // Serial input data
  input din_valid,  // Validity signal for input data
  output reg [7:0] dout_parallel, // Parallel output data (8 bits wide)
  output reg dout_valid          // Validity signal for the output data
);

  reg [3:0] cnt;  // 4-bit counter to keep track of the number of serial input bits received

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin   // Asynchronous active low reset
      cnt <= 4'b0;      // Reset counter
      dout_valid <= 1'b0; // Reset validity signal
      dout_parallel <= 8'b0; // Reset parallel output data
    end
    else begin
      if (din_valid) begin
        if (cnt == 4'b1111) begin
          cnt <= 4'b0;  // Reset counter
          dout_valid <= 1'b1; // Set validity signal
        end
        else begin
          cnt <= cnt + 1;  // Increment counter
          dout_valid <= 1'b0; // Reset validity signal
        end
        dout_parallel <= {din_serial, dout_parallel[7:1]};  // Shift din_serial to the left and update parallel output data
      end
    end
  end

endmodule
```

In this code, a 4-bit counter (`cnt`) is used to keep track of the number of serial input data bits received. The `dout_parallel` output is a register that stores the 8-bit parallel output data, and `dout_valid` is a register that indicates the validity of the output data.

The `always` block is sensitive to the positive edge of the clock (`clk`) and the negative edge of the reset signal (`rst_n`). Inside the block, an asynchronous active low reset is implemented to initialize the counter and output registers when `rst_n` is low.

When `din_valid` is high, indicating valid input data, the circuit checks if the counter (`cnt`) has reached the value `4'b1111`, which corresponds to 8 input data bits. If so, the counter is reset, `dout_valid` is set high to indicate the validity of the output data, and the `din_serial` input is shifted into the least significant bit of `dout_parallel`. Otherwise, the counter is incremented, `dout_valid` is set low, and `din_serial` is shifted into `dout_parallel` by shifting all the bits to the left.
