Here is the complete code for the 8-bit Radix-4 Booth multiplier in Verilog:

```verilog
module multi_booth_8bit(
    input clk,
    input reset,
    input [7:0] a,
    input [7:0] b,
    output reg [15:0] p,
    output reg rdy
);

reg [7:0] multiplier;
reg [7:0] multiplicand;
reg [4:0] ctr;

always @(posedge clk or posedge reset) begin
    if (reset) begin
        multiplier <= {8{a[7]}};
        multiplicand <= {8{b[7]}};
        ctr <= 0;
        p <= 0;
        rdy <= 0;
    end else begin
        if (ctr < 16) begin
            multiplicand <= {multiplicand[6:0], multiplicand[7]};
            if (multiplier[ctr]) begin
                p <= p + multiplicand;
            end
            ctr <= ctr + 1;
        end else begin
            rdy <= 1;
        end
    end
end

endmodule
```

In this code, the multiplier and multiplicand registers are initialized on reset and the counter (ctr) is set to 0. During normal operation, the multiplicand is left-shifted by 1 each clock cycle and the product (p) accumulates the value of the multiplicand if the current bit of the multiplier is 1. The counter is incremented until it reaches 16, at which point the ready signal (rdy) is set to 1 to indicate the completion of the multiplication process.
