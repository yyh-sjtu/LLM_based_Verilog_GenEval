```verilog
module right_shifter (
  input clk,
  input d,
  output reg [7:0] q
);

  // Initialize q to 0
  initial begin
    q <= 8'b0;
  end

  // Shift the contents of q to the right by 1 bit and insert d at q[7]
  always @(posedge clk) begin
    q <= {d, q[7:1]};
  end

endmodule
```

The q register is declared as a reg [7:0] and initialized to 0 using the initial statement. On each rising edge of the clock, the q register is right-shifted by 1 bit using the bitwise concatenation operator ({}) and the most significant bit (q[7]) is assigned the value of the input signal (d).
