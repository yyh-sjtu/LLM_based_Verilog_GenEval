Here's the complete code for the requested dual-port RAM implementation in Verilog:

```verilog
module RAM #(parameter WIDTH=6, DEPTH=8) (
  input wire clk,
  input wire rst_n,
  input wire write_en,
  input wire [WIDTH-1:0] write_addr,
  input wire [WIDTH-1:0] write_data,
  input wire read_en,
  input wire [WIDTH-1:0] read_addr,
  output wire [WIDTH-1:0] read_data
);

  reg [WIDTH-1:0] RAM [DEPTH-1:0];

  // Write Operation
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      RAM <= '{DEPTH{WIDTH'h00}};
    end else begin
      if (write_en) begin
        RAM[write_addr] <= write_data;
      end
    end
  end

  // Read Operation
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      read_data <= {WIDTH{1'b0}};
    end else begin
      if (read_en) begin
        read_data <= RAM[read_addr];
      end else begin
        read_data <= {WIDTH{1'b0}};
      end
    end
  end

endmodule
```

Note that the code assumes a synchronous design where the read and write operations are synchronized with the clock signal (clk) and the reset signal (rst_n) is active-low. The RAM array is implemented using a reg data type with two dimensions - DEPTH for the number of memory locations and WIDTH for the bit width of each memory location. On reset, the entire RAM array is initialized to 0. During write operations, the write_data is written to the specified write_addr in the RAM array. During read operations, the data at the specified read_addr in the RAM array is assigned to read_data. If the read_en signal is not active, read_data is cleared to 0.
