Here is the complete code for the counter design in Verilog:

```verilog
module counter_12 (
  input rst_n,
  input clk,
  input valid_count,
  output reg [3:0] out
);

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)   // Reset signal is active low
      out <= 4'b0000;
    else if (valid_count) begin
      if (out == 4'd11)
        out <= 4'b0000;   // Counter wraps around and resets to 0
      else
        out <= out + 1;   // Increment counter
    end
  end

endmodule
```

In this code, a synchronous always block is used with the `posedge clk` condition to control the counter behavior. The counter is reset to 0 when the `rst_n` signal is active low. 

When the `valid_count` signal is active, the code checks if the current count value `out` is equal to 4'd11 (maximum count value). If it is, the counter wraps around and resets to 0. Otherwise, it increments the counter value by 1.

If the `valid_count` signal is not active (0), the counter stops, and the output register `out` remains unchanged.
