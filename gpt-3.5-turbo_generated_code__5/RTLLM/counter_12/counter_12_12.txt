```verilog
module counter_12 (rst_n, clk, valid_count, out);
  input rst_n; // Reset signal (active low)
  input clk; // Clock signal
  input valid_count; // Signal to enable counting
  output reg [3:0] out; // 4-bit output representing the current count value

  always @(posedge clk, negedge rst_n)
  begin
    if (!rst_n) // Reset condition
      out <= 4'b0000;
    else if (valid_count && (out == 4'd11)) // Increment and wrap around
      out <= 4'b0000;
    else if (valid_count) // Increment
      out <= out + 1;
  end
endmodule
```

On each positive edge of the clock signal `clk`, the counter checks the value of `valid_count`. If `valid_count` is high (1) and the current count value `out` is equal to 4'd11, the counter wraps around by assigning the value 4'b0000 to `out`. This means that when the counter reaches the maximum count value, it resets to 0.

If `valid_count` is high (1) and the counter is not at the maximum count value, `out` is incremented by 1.

If `valid_count` is low (0), the counter will stop, and the value of `out` remains unchanged.
