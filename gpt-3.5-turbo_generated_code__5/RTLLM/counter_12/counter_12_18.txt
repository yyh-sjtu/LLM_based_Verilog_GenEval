Here's the complete code for the counter design described:

```verilog
module counter_12(
  input rst_n,
  input clk,
  input valid_count,
  output reg [3:0] out
);

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
      out <= 4'b0000;
    end else if (valid_count) begin
      if (out == 4'd11) begin
        out <= 4'b0000;
      end else begin
        out <= out + 1;
      end
    end
  end

endmodule
```

In this design, a synchronous always block is used to define the counter's behavior. It triggers on the positive edge of the clk signal and the negative edge of the rst_n signal.

If the rst_n signal is active low, the counter is reset to 0 by assigning 4'b0000 to the output register (out).

If the valid_count signal is active, the counter increments. It checks if the current count value (out) is equal to 4'd11 (maximum count value). If it is, the counter wraps around and resets to 0 by assigning 4'b0000 to the output register (out). Otherwise, it increments the output register by 1.

If the valid_count signal is inactive (0), the counter will pause, and the output register (out) remains unchanged.
