Here is the complete code for the counter design in Verilog:

```verilog
module counter_12 (
    input rst_n,
    input clk,
    input valid_count,
    output reg [3:0] out
);

    always @(posedge clk or negedge rst_n)
    begin
        if (!rst_n)             // Reset condition
            out <= 4'b0000;
        else if (valid_count)   // Count only when valid_count is active
        begin
            if (out == 4'd11)   // Wrap around to 0 when maximum value is reached
                out <= 4'b0000;
            else
                out <= out + 1; // Increment the count value
        end
    end

endmodule
```

In this code, the counter design is implemented as a synchronous always block, sensitive to the positive edge of the clock signal (clk) and the negative edge of the reset signal (rst_n). 

Inside the always block, if the reset signal is active (rst_n = 0), the counter is reset to 0 by assigning 4'b0000 to the output register (out). 

If the valid_count signal is 1, the counter increments. It first checks if the current count value (out) is equal to 4'd11, which is the maximum count value. If it is, the counter wraps around and resets to 0 by assigning 4'b0000 to the output register (out). Otherwise, it increments the output register (out) by 1. 

If the valid_count signal is 0, the counter stops and the output register (out) remains unchanged until the valid_count signal becomes active again.

Note that the code assumes you are using a synchronous reset (active low) and a positive edge-triggered clock.
