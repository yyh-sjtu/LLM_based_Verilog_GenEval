Here is the Verilog code for the Multiplying Accumulator:

```
module pe(
    input clk,
    input rst,
    input [31:0] a,
    input [31:0] b,
    output reg [31:0] c
);

always @(posedge clk or posedge rst) begin
    if (rst) begin
        c <= 0;
    end else begin
        c <= c + (a * b);
    end
end

endmodule
```

In this code, the `pe` module takes in the clock signal (`clk`), reset signal (`rst`), and two 32-bit input operands (`a` and `b`). It outputs the accumulated result (`c`) as a 32-bit value.

The always block triggers on the positive edge of the clock signal or the positive edge of the reset signal. If the reset signal is high (`rst == 1`), indicating a reset condition, the accumulator register `c` is set to 0. If the reset signal is low (`rst == 0`), the module adds the product of the input operands `a` and `b` to the current value of `c`.

Note that the `output reg` declaration for the output port `c` indicates that it is a registered output.
