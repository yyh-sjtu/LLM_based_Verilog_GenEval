  output reg [7:0] anyedge

      if (in[i] && !prev_in[i]) // Detect rising edge
        anyedge[i] <= 1'b1; // Set output bit in the next cycle
      else
        anyedge[i] <= 1'b0; // Reset output bit
    end
  end

endmodule

On each rising edge of the clock signal `clk`, a for loop is used to iterate through each bit of the input vector. If a rising edge is detected in any bit (in[i] is high and prev_in[i] is low), the corresponding bit in the `anyedge` output is set to high in the next cycle. Otherwise, the output bit is reset to low.
