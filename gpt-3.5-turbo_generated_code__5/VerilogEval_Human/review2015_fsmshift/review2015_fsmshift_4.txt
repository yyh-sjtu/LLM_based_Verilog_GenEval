```verilog
module top_module(
    input clk,
    input reset,
    output shift_ena);
    
    reg [3:0] count;
    reg shift_ena;
    
    always @(posedge clk or posedge reset) begin
        if(reset) begin
            count <= 4'b1111;
            shift_ena <= 1'b1;
        end
        else if(count > 4'b0000) begin
            count <= count - 1;
            shift_ena <= 1'b1;
        end
        else begin
            count <= 4'b0000;
            shift_ena <= 1'b0;
        end
    end
    
endmodule
```

Explanation:

- In the `top_module`, there are three primary inputs: `clk`, `reset`, and `output shift_ena`.
- The module uses two registers: `count` to keep track of the number of clock cycles and `shift_ena` to control the shift register enable signal.
- Inside the `always` block, an `if-else` construct is used to handle the synchronous reset and the shift enable logic.
- When the `reset` signal is high, the `count` is initialized to 4'b1111 and `shift_ena` is set to 1'b1. This enables the shift register for the first 4 clock cycles after reset.
- If the `count` is greater than 4'b0000, the `count` is decremented by 1 and `shift_ena` remains high, allowing the shift register to continue for another clock cycle.
- Once the `count` reaches 4'b0000, it is set back to 4'b0000 and `shift_ena` is set to 1'b0, indicating that the shift register should no longer be enabled until the next reset signal.
- The module does not have any explicit output assignment for `shift_ena` as it is updated in the `always` block. The output `shift_ena` will reflect the value present in the `shift_ena` register.
