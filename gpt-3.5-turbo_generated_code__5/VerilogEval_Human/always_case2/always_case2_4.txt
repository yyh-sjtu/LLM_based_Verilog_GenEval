Here is the Verilog code for a 4-bit priority encoder:

```verilog
module priority_encoder_4bit (
  input [3:0] in,
  output reg [1:0] pos
);

  always @*
  begin
    casex (in)
      4'b0000: pos = 2'b00;
      4'b0001: pos = 2'b01;
      4'b0010: pos = 2'b10;
      4'b0011: pos = 2'b11;
      4'b0100: pos = 2'b00;
      4'b0101: pos = 2'b01;
      4'b0110: pos = 2'b10;
      4'b0111: pos = 2'b11;
      4'b1000: pos = 2'b00;
      4'b1001: pos = 2'b01;
      4'b1010: pos = 2'b10;
      4'b1011: pos = 2'b11;
      4'b1100: pos = 2'b00;
      4'b1101: pos = 2'b01;
      4'b1110: pos = 2'b10;
      4'b1111: pos = 2'b11;
    endcase
  end

endmodule
```

In this code, a combinational `always @*` block is used to assign the output `pos` based on the values of the input signal `in`. The `casex` statement is used to define the possible input combinations and the corresponding output values. For example, `4'b0001` corresponds to the input value 1, so the output `pos` is assigned the value 2'b01. The `reg` keyword is used to define `pos` as a 2-bit output signal.
