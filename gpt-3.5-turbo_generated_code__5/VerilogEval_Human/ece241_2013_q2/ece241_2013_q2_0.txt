The Verilog code below represents the single-output digital system as described:

```verilog
module top_module (
	input a,
	input b,
	input c,
	input d,
	output out_sop,
	output out_pos
);

	// Output Declarations
	wire out_sop;
	wire out_pos;

	// SOP Form Calculation
	assign out_sop = (~a & ~b & ~c & d) | (~a & b & ~c & ~d) | (~a & ~b & c & ~d);

	// POS Form Calculation
	assign out_pos = (a | b | c | ~d) & (a | ~b | c | d) & (~a | b | ~c | d);

endmodule
```

In the above code, `out_sop` represents the output in minimum sum-of-products form and `out_pos` represents the output in minimum product-of-sums form. The SOP form is calculated using OR operations on the desired input combinations, while the POS form is calculated using AND operations on the complemented desired input combinations.
