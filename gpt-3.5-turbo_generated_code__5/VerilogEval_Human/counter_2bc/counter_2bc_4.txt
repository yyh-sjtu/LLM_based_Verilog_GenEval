Here is the Verilog code for the two-bit saturating counter:

```verilog
module top_module(
    input clk,
    input areset,
    input train_valid,
    input train_taken,
    output logic [1:0] state
);
    always @(posedge clk or posedge areset) begin
        if (areset) begin
            state <= 2'b01;  // Reset to weakly not-taken
        end else if (train_valid) begin
            if (train_taken & (state != 2'b11)) begin
                state <= state + 1;  // Increment when train_valid = 1 and train_taken = 1
            end else if (!train_taken & (state != 2'b00)) begin
                state <= state - 1;  // Decrement when train_valid = 1 and train_taken = 0
            end
        end
    end
endmodule
```

In this code, the counter state is stored in the `state` variable, which is a two-bit logic vector. The counter is synchronous with the `clk` signal and can be asynchronously reset using the `areset` signal.

The counter increments when both `train_valid` and `train_taken` are asserted (equal to 1), up to a maximum value of 3 (2'b11). It decrements when `train_valid` is asserted but `train_taken` is de-asserted (equal to 0), down to a minimum value of 0 (2'b00). When `train_valid` is de-asserted, the counter retains its current value.

Please note that this code assumes a positive edge-triggered clock (`clk`) and a positive edge-triggered asynchronous reset (`areset`). The counter outputs the current counter value through the `state` output port.
