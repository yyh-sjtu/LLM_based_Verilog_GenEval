```systemverilog
module TopModule(
  input [7:0] in,
  output reg [2:0] pos
);

  always @(*) begin
    casex(in)
      // Check each bit in the input vector starting from the least significant bit
      // When a high bit is found, assign the corresponding position to the output
      8'b00000001: pos = 3'b0; // bit 0
      8'b00000010: pos = 3'b1; // bit 1
      8'b00000100: pos = 3'b2; // bit 2
      8'b00001000: pos = 3'b3; // bit 3
      8'b00010000: pos = 3'b4; // bit 4
      8'b00100000: pos = 3'b5; // bit 5
      8'b01000000: pos = 3'b6; // bit 6
      8'b10000000: pos = 3'b7; // bit 7
      default: pos = 3'b0; // No high bits found
    endcase
  end

endmodule
```

In this implementation, the `casex` statement is used to check the input vector against each possible combination of high bits. The position of the first high bit found is then assigned to the `pos` output signal. If no high bits are found, `pos` is assigned zero.

Note that in SystemVerilog, the positions in a vector are indexed from 0 to N-1, where N is the width of the vector. So, in the `pos` output signal, the least significant bit is represented by `pos[0]`, and the most significant bit is represented by `pos[2]`.
