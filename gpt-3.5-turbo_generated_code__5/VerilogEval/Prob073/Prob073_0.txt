```verilog
module TopModule(
  input clk,
  input resetn,
  input [1:0] byteena,
  input [15:0] d,
  output [15:0] q
);

  reg [15:0] q_reg;
  
  always @(posedge clk) begin
    if (!resetn) begin
      q_reg <= 16'b0;
    end else begin
      if (byteena[0])
        q_reg[7:0] <= d[7:0];
      if (byteena[1])
        q_reg[15:8] <= d[15:8];
    end
  end
  
  assign q = q_reg;
  
endmodule
```

In this implementation, `q_reg` is a 16-bit register that holds the values of the 16 D flip-flops. On each positive edge of the clock (`clk`), the values in the `d` input are written to the appropriate bytes of the `q_reg` based on the values of `byteena`. The values in `q_reg` are output as `q`. 

The `resetn` input is an active-low synchronous reset. When `resetn` is low, all the flip-flops are reset to 0.
