Sure, here is an implementation of the TopModule in VHDL:

```vhdl
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity TopModule is
    Port (  
        clk     : in  STD_LOGIC;        -- Clock signal
        resetn  : in  STD_LOGIC;        -- Synchronous, active-low reset signal
        byteena : in  STD_LOGIC_VECTOR(1 downto 0);  -- Byte enable input
        d       : in  STD_LOGIC_VECTOR(15 downto 0); -- Input data
        q       : out STD_LOGIC_VECTOR(15 downto 0) -- Output data
    );
end TopModule;

architecture Behavioral of TopModule is

    signal register_a : STD_LOGIC_VECTOR(15 downto 0); -- 16-bit register

begin

    process (clk)
    begin
        if rising_edge(clk) then
            if resetn = '0' then  -- Synchronous reset
                register_a <= (others => '0');
            else
                -- Update the register based on the byte enable signals
                if byteena(0) = '1' then
                    register_a(7 downto 0) <= d(7 downto 0);
                end if;
                
                if byteena(1) = '1' then
                    register_a(15 downto 8) <= d(15 downto 8);
                end if;
            end if;
        end if;
    end process;

    q <= register_a; -- output the value from the register

end Behavioral;
```

In this implementation, the TopModule contains a `register_a` signal which is a 16-bit register implemented using D flip-flops. On the rising edge of the clock signal (`clk`), the module checks the reset signal (`resetn`). If the reset signal is low, it clears the register to all zeros. Otherwise, it updates the register based on the byte enable signals (`byteena`). 

If the `byteena(0)` is high, it writes the lower byte of `d` to the lower byte of the register. If the `byteena(1)` is high, it writes the upper byte of `d` to the upper byte of the register.

Finally, the `q` output is assigned the value of the register to reflect the updated value on the output.

Please note that this implementation assumes that the flip-flops used are positive-edge triggered D flip-flops, as specified in the problem statement.
