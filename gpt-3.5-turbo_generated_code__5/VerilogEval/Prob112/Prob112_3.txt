```verilog
module TopModule (
    input [3:0] in,
    output [1:0] pos
);

assign pos = 2'b00;

    case(in)

        4'b0010: pos = 2'b01;
        4'b0100: pos = 2'b10;
        4'b1000: pos = 2'b11;
        default: pos = 2'b00;
    endcase
end

endmodule
```

The priority encoder logic is implemented using a `case` statement that checks the input vector and assigns the appropriate output based on the position of the first high bit. If none of the input bits are high, the output is set to zero.
