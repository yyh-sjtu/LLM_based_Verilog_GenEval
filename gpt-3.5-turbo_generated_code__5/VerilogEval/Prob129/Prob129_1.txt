Here is an example Verilog implementation of the TopModule with the specified interface and functionality:

```verilog
module TopModule (
    input           clk,
    input           aresetn,
    input           x,
    output reg      z
);

// Define states for the FSM
parameter S0 = 2'b00;
parameter S1 = 2'b01;
parameter S2 = 2'b10;

// Define state register
reg [1:0] state, next_state;

always @(posedge clk or negedge aresetn) begin
    if (!aresetn) begin
        state <= S0;
    end else begin
        state <= next_state;
    end
end

always @* begin
    next_state = state;
    z = 1'b0; 
    case(state)
        S0: begin
            if (x == 1'b1) begin
                next_state = S1;
            end
        end
        
        S1: begin
            if (x == 1'b0) begin
                next_state = S0;
            end else begin
                next_state = S2;
            end
        end
        
        S2: begin
            if (x == 1'b1) begin
                z = 1'b1;
                next_state = S1;
            end
        end
    endcase
end

endmodule
```

This Verilog code defines the TopModule module with a Mealy-type finite state machine that recognizes the "101" sequence on input signal x. The output signal z is asserted to logic-1 when the sequence is detected. The FSM has 3 states and an asynchronous reset signal aresetn. The sequential logic is triggered on the positive edge of the clock signal.
