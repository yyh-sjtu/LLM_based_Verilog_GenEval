```verilog
module TopModule (
  input  clk,
  input  reset,
  input  slowena,
  output reg [3:0] q
);

  reg [3:0] count;

  always @(posedge clk) begin
    if (reset)
      count <= 0;
    else if (slowena)
      count <= count + 1;
  end

  assign q = count;

endmodule
```

Inside the always block, we use the positive edge of the clock (`@(posedge clk)`) to trigger the counting behavior. If `reset` is high, we set `count` to 0. Otherwise, if `slowena` is high, we increment `count` by 1.

At the end, we assign the value of `count` to the output `q`.
