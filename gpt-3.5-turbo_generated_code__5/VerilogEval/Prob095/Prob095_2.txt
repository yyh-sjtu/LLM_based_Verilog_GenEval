Here is an RTL implementation of the TopModule with the described interface:

```verilog
module TopModule (
    input clk,
    input reset,
    output reg shift_ena
);

reg [3:0] shift_cnt;

always @(posedge clk) begin
    if (reset) begin
        shift_ena <= 1;
        shift_cnt <= 4'b1111;
    end else begin
        if (shift_cnt > 0) begin
            shift_ena <= 1;
            shift_cnt <= shift_cnt - 1;
        end else begin
            shift_ena <= 0;
        end
    end
end

endmodule
```

In this implementation, the `shift_ena` output is controlled by the `shift_cnt`, which counts down from 4 when the FSM is not in the reset state. The `shift_ena` is asserted for 4 clock cycles, then de-asserted until the next reset. The synchronous reset is used to initialize the shift count and ensure proper behavior when the FSM is reset.
