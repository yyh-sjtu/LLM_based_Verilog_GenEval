```verilog
module TopModule(
  input clk,
  input areset,
  input predict_valid,
  input predict_taken,
  input train_mispredicted,
  input train_taken,
  input [31:0] train_history,
  output [31:0] predict_history
);
  reg [31:0] history_reg;
  reg [31:0] new_history;

  always @(posedge clk or posedge areset) begin
    if (areset)
      history_reg <= 0;
    else if (train_mispredicted)
      history_reg <= {train_history, train_taken};
    else if (predict_valid)
      history_reg <= {history_reg[30:0], predict_taken};
  end

  assign predict_history = history_reg;
endmodule
```

This implementation uses a positive edge-triggered clock and a positive edge-triggered asynchronous reset signal `areset`. The `history_reg` register is used to store the branch history, and `new_history` is used to update the `history_reg` in each clock cycle.

In the `always` block, the logic for updating the branch history is implemented. If `areset` is active, the `history_reg` is reset to zero. If `train_mispredicted` is active, the `history_reg` is updated with the concatenation of `train_history` and `train_taken`. If `predict_valid` is active, the `history_reg` is updated with the shifted value of `history_reg` and the new prediction `predict_taken`.

Finally, the `predict_history` output is directly assigned to the `history_reg`.
