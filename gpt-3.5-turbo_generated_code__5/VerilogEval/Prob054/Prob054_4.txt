As a professional RTL designer, I would implement the TopModule module as follows:

```verilog
module TopModule (
  input clk,
  input [7:0] in,
  output reg [7:0] pedge
);

reg [7:0] prev_in;

always @(posedge clk) begin
  prev_in <= in;
  
  for (int i=0; i<8; i=i+1) begin
    if (prev_in[i] == 0 && in[i] == 1)
      pedge[i] <= 1;
    else
      pedge[i] <= 0;
  end
end

endmodule
```

In this implementation, I have used a synchronous always block triggered by the positive edge of the clk signal. Inside the always block, a for loop iterates over each bit of the input vector. It compares the current bit (in[i]) with the corresponding bit in the previous cycle (prev_in[i]). If the previous bit was 0 and the current bit is 1, the output bit pedge[i] is set to 1. Otherwise, it is set to 0.

I have also added a register prev_in to store the input vector in the previous cycle. This is necessary for the comparison.
