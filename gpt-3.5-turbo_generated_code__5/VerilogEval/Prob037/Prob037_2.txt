Sure, here is an RTL design for the TopModule module:

```verilog
module TopModule (
    input clk,
    input reset,
    output [9:0] q
);

reg [9:0] counter;

always @(posedge clk) begin
    if (reset) begin
        counter <= 10'b0;
    end else begin
        if (counter < 10'd999) begin
            counter <= counter + 10'd1;
        end else begin
            counter <= 10'b0;
        end
    end
end

assign q = counter;

endmodule
```

This design implements a counter that counts from 0 to 999 with a period of 1000 cycles. The counter is reset to 0 when the reset input is active high. The sequential logic is triggered on the positive edge of the clock signal. The output q is a 10-bit signal that represents the current count value.
