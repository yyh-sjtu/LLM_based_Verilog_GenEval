```verilog
module TopModule (
  input clk,
  input reset,
  output reg [9:0] q
);

  always @(posedge clk) begin
    if (reset)
      q <= 0;
    else if (q == 999)
      q <= 0;
    else
      q <= q + 1;
  end

endmodule
```

In this implementation, a synchronous always block is used to capture the positive edge of the clock signal. Inside the always block, we check for the reset input and if it is high, we set the counter (`q`) to 0. If the reset input is low, we check if the counter (`q`) has reached the maximum value of 999. If it has, we wrap around and set the counter back to 0. Otherwise, we increment the counter by 1.

Note that the counter is a 10-bit wide register, which allows it to hold values from 0 to 999.
