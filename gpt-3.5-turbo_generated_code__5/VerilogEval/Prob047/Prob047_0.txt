```verilog
module TopModule (
    input clk,
    input areset,
    input [7:0] d,
    output reg [7:0] q
);

reg [7:0] d_ff;

always @(posedge clk or posedge areset) begin
    if (areset) begin
        d_ff <= 8'b0;
    end else begin
        d_ff <= d;
    end
end

always @* begin
    q = d_ff;
end

endmodule
```

In this code, the TopModule module contains 8 D flip-flops with an active high asynchronous reset. The input data 'd' is stored in 'd_ff' on the positive edge of the clock signal. The output 'q' is assigned the value of 'd_ff', which is initialized to 0 when the asynchronous reset signal 'areset' is high.
