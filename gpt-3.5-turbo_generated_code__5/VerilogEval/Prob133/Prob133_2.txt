As an RTL designer, I will create a Verilog module named TopModule to implement the desired functionality.

```verilog
module TopModule(
  input  clk,
  input  reset,
  input  s,
  input  w,
  output reg z
);

  reg [1:0] state;
  reg [2:0] w_count;

  always @(posedge clk) begin
    if (reset) begin
      state <= 2'b00;
      w_count <= 3'b000;
      z <= 1'b0;
    end else begin
      case (state)
        2'b00: begin // State A
          if (s) begin
            state <= 2'b01; // Transition to state B
            w_count <= 3'b000;
          end
        end
        2'b01: begin // State B
          w_count <= {w_count[1:0], w}; // Shift in w value
  
          if (w_count == 3'b011)  // Check for two 1's in three clock cycles
            z <= 1'b1;
          else if (w_count == 3'b100)
            z <= 1'b0;  
  
          state <= 2'b01; // Stay in state B
        end
      endcase
    end
  end

endmodule
```

In this module, I have created a state variable "state" and a count variable "w_count" to keep track of the current state and the number of consecutive "1" inputs observed. 

Inside the always block, I have implemented the state machine logic. On reset, the state is set to 2'b00 (state A), and the count is initialized to 3'b000. The output "z" is set to 1'b0.

In state A, we check if input "s" is high. If it is, we transition to state 2'b01 (state B) and reset the count. If "s" is low, we stay in state A and monitor the input "w".

In state B, we shift in the value of "w" into the count register "w_count". We then compare the value of "w_count" to 3'b011 (two "1" inputs in three clock cycles) and 3'b100 (no two "1" inputs in three clock cycles) to determine the output "z". We always stay in state B for the next clock cycle.

This design utilizes two states, one for state A and one for state B, as requested to minimize the number of states used.
