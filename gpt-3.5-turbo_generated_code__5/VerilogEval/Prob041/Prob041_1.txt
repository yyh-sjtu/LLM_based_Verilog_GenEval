Here is the RTL code implementation for the TopModule:

```verilog
module TopModule (
    input       clk,
    input       reset,
    input [7:0] d,
    output reg [7:0] q
);

reg [7:0] d_ff;

always @(posedge clk or posedge reset) begin
    if (reset) begin
        d_ff <= 8'b0;
    end else begin
        d_ff <= d;
    end
end

assign q = d_ff;

endmodule
```

This code implements a module named TopModule with the specified interface. It includes 8 D flip-flops triggered by the positive edge of the clock and with an active high synchronous reset that sets the output q to zero. The input d is stored in a register d_ff and assigned to the output q.
