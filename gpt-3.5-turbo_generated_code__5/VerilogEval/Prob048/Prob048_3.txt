```verilog
module TopModule (
  input clk,
  input d,
  input r,
  output reg q
);

  always @(posedge clk) begin
    if (r == 1'b1)      // Active high synchronous reset
      q <= 1'b0;
    else
      q <= d;
  end

endmodule
```

Inside the always block, we check the value of the "r" input. If "r" is high (1), indicating a reset condition, we set the output "q" to low (0). Otherwise, we assign the value of the "d" input to the output "q".
