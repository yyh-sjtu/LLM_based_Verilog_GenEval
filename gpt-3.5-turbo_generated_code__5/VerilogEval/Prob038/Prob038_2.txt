```verilog
module TopModule (
    input  clk,
    input  reset,
    output reg [3:0] q
);

always @(posedge clk) begin
    if (reset) begin
        q <= 4'b0000; // Reset the counter to 0
    end else begin
        if (q == 4'b1111) begin
            q <= 4'b0000; // Reset the counter when it reaches 15
        end else begin
            q <= q + 1; // Increment the counter
        end
    end
end

endmodule
```

In this implementation, an always block is used to trigger the sequential logic on the positive edge of the clock. If the reset input is high, the counter `q` is set to 0. Otherwise, when the counter reaches its maximum value of 15 (represented by 4'b1111), it is reset to 0. Otherwise, the counter is incremented by 1 in each clock cycle.

Note that `output reg [3:0] q` is used to define a 4-bit output `q`. The `reg` keyword indicates that this is a combinational output that can be assigned within an always block.
